## Native Kaggle launcher (v0.13.0)

`OcuWeave_Native_Kaggle.ipynb` builds and tests the C++/CUDA backend, then optionally runs the frozen FIVES classification baseline. Attach the exact manifest and original data; GPU/internet account verification is required. The training gate defaults to false. It does not automatically resume historical Colab segmentation runs. See the [protocol and execution status](../docs/protocols/native/classification.md).
