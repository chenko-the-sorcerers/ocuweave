# Software validation: OcuWeave 0.11.0

Date: 2026-11-01. Scope: software integration on synthetic data, not a clinical experiment.

## Local validation

- Python: 84 tests passed, including native parity, exact CPU interrupted-run equivalence, three-task CLI/API flows, missing-label gradients, missing modalities and original-grid/tile geometry.
- CMake/CTest: 2/2 passed (weighted pooling and binary confusion counts).
- Synthetic manifest audit: three samples across train/validation/test; structural fixture only.
- Wheel built and installed in a separate environment. `doctor`, `demo`, `demo-tasks` and `demo-multimodal` completed from outside the checkout; import resolved to `site-packages`.
- `demo-tasks` completed synthetic FIVES/IDRiD training, checkpoint reload, original-grid validation, inference and training-only diagnostics. Both receipts report `gpu_executed=false` and `test_evaluated=false`.
- Multimodal demo checked forward/backward execution with one observed and one missing note/structured modality pair. No clinical records or pretrained LLM were used.
- Release metadata synchronization and Git whitespace checks passed. Continuous integration independently runs the suite on Linux after publication; its status is available in GitHub Actions.

Environment: macOS arm64, Python 3.12.4, PyTorch 2.11.0, NumPy 2.5.4, Pillow 12.3.0, SciPy 1.18.1, scikit-image 0.26.0. Device: CPU. An existing Matplotlib/NumPy deprecation warning did not fail the suite.

## Research interpretation

No medical dataset was trained in this update. Historical OTFID/FIVES/IDRiD measurements remain unchanged. The core GPU matrix and medical-data readiness checks are still pending. The new fixed-step runner is a separate software protocol; it does not retrospectively alter old run definitions. Synthetic numerical success does not establish clinical annotation correctness, patient independence, multimodal benefit or diagnostic performance.
