# IDRiD — lesion-specific segmentation cohort

[Official data page](https://idrid.grand-challenge.org/Data/); [original descriptor](https://doi.org/10.3390/data3030025). The pixel-annotated subset has 81 fundus images and lesion masks for microaneurysms, haemorrhages, hard exudates and soft exudates. It differs from the larger disease-grading dataset. The source lists unequal mask availability across classes; missing files must not silently become negative targets.

Use four independent output channels, preserve each class mask, and record supervision availability per image/class. Audit actual release filenames, mask encodings, patient/eye linkage, duplicate candidates and official partitions before freezing development data. Do not collapse all lesion types into a binary union and call the result multi-class performance. Pixel-level masks do not constitute paired narrative EMR.

The official page identifies CC BY 4.0; verify the acquired release and retain attribution. The official IEEE download requires login. The feasibility workflow uses the original segmentation ZIP redistributed by a third party at [Zenodo record 17219542](https://zenodo.org/records/17219542), with its provenance and transfer checksum recorded. Byte equivalence to the authenticated IEEE source is not established. A four-channel adapter/trainer is implemented; unavailable masks remain unknown. The [core experiment programme](../protocols/cross_task_experiments.md) remains unexecuted; the separate [100-step CPU feasibility report](../results/cross-task-feasibility-v0100/README.md) records measured validation results. The 2018 descriptor is an explicit dataset-definition exception to the recent-literature preference.
