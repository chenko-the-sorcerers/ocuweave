# FIVES feasibility protocol

Prespecified on 2026-11-01 before FIVES model training. This supplementary CPU study responds to unavailable Colab GPU allocation. It does not replace or complete the 500-step cross-task programme or the frozen OTFID suite.

- Source: Jin et al., FIVES official Figshare v1, DOI 10.6084/m9.figshare.19688169.v1, file 34969398, 1,764,974,308 bytes, MD5 `789c80dd5376a82063e27fa49192bac9`, CC BY 4.0. Preserve the original archive and metadata in project Drive.
- Audit: pair exact filenames within official partitions; verify dimensions and binary encoding, hash files and decoded RGB, group dHash candidates only when thumbnail RMSE <=0.025. Reject a group crossing official train/test partitions pending adjudication. Keep quality-flagged images; the official quality spreadsheet remains available. Technical review cannot adjudicate clinical annotation correctness.
- Split: retain the official test partition. Within each disease stratum, seed 42 assigns approximately 20% of training similarity groups to validation. Patient and eye identities remain unverified. Disease strata are context, not segmentation targets.
- Variants: Query 192, Query 384, LQNet 384; width 24, embedding 48, eight queries, random initialization, seed 42, 100 optimizer steps, batch size eight. A smoke pass checks finite loss/gradients, then its weights and data ordering are discarded.
- Pipeline: RGB/255, aspect-preserving bilinear image resize and nearest-neighbor reference mask resize, letterbox padding excluded from BCE plus soft Dice; paired horizontal flips with probability 0.5. AdamW learning rate 0.001, decay 0.0001, cosine schedule over optimizer steps, gradient clipping 1, float32, two CPU threads.
- Checkpoint: final step fixed in advance; no validation-driven checkpoint selection or threshold tuning. Reload equivalence required. Training runtime includes lazy image decoding. CUDA memory is null on CPU, not zero.
- Evaluate validation once after training, restoring probabilities to the original grid before thresholding at 0.5. Report per-image and macro Dice/IoU, sensitivity, precision, false-positive area divided by full image area, clDice, and thin reference-centerline recall (distance to background <=2 original pixels). Undefined precision/recall values are null and excluded from those means; per-image records supply denominators. No test inference.
- clDice uses skeleton precision (predicted skeleton inside reference) and skeleton sensitivity (reference skeleton inside prediction), then their harmonic mean. Empty/empty is one; an unmatched nonempty skeleton scores zero. Radius is Euclidean distance in original image pixels, not a clinical vessel caliber.
- Gallery: lowest, median and highest validation Dice, plus greatest false-positive area, deduplicated. Display original image, reference and prediction separately. These are illustrative feasibility outputs, not evidence of diagnosis or clinical readiness.
- Interpretation: one seed and a short CPU budget cannot establish superiority. Resolution and local-detail contrasts must retain their paired budgets. Full-resolution/patch alternatives require a separate protocol because aggressive resizing may discard narrow vessels.

IDRiD and REFUGE2 are not replaced with FIVES disease strata: FIVES vessel labels cannot train DR lesion classes or disc/cup segmentation. Those cohorts remain blocked on their official access workflow.
